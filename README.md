### Activation success metrics

Useful performance indicators include:

| Metric                     | Definition                                                            |
| -------------------------- | --------------------------------------------------------------------- |
| Activation success rate    | Completed verifications divided by total eligible attempts            |
| SMS delivery rate          | Attempts that receive a message divided by total eligible attempts    |
| Time to receive code       | Time between requesting verification and receiving the SMS            |
| First-attempt success rate | Verifications completed without requesting another number             |
| Refund rate                | Eligible failed transactions that result in a refund                  |
| Number availability rate   | Requests fulfilled from available inventory divided by total requests |

These metrics should be measured over a defined period and separated by country, platform, and number type where possible.

### Pricing transparency

Clear prices and refund conditions make it easier to estimate the actual cost of successful verification. The lowest advertised price may not produce the lowest cost per completed activation if many attempts fail.

### Privacy and account security

A temporary or shared phone number may not be suitable for sensitive accounts. Other users might access messages sent to a reused number, and access to the number may not continue after the activation ends.

For important accounts, a personal number or another supported authentication method is generally safer.
